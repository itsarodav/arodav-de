# arodav

Portfolio y blog personal construido con [Astro](https://astro.build/), GSAP y Sass.

Soporta inglés y español, tema claro/oscuro, y sección de escritura (blog).

## Requisitos

- Node.js 18+

## Comandos

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo
npm run build    # build de producción
npm run preview  # previsualizar build
```
